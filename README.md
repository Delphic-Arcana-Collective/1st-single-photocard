# Delphic — 1st Single

Next.js photocard flip page, built with [Bun](https://bun.sh).

## Prerequisites

- [Bun](https://bun.sh) 1.4+

## Getting Started

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000).

Edit `src/app/page.tsx` — the page hot-reloads as you save.

## Scripts

| Command | Description |
| --- | --- |
| `bun run dev` | Development server (Bun runtime) |
| `bun run build` | Production build (Bun runtime) |
| `bun run start` | Serve the production build |
| `bun run lint` | Run ESLint |
